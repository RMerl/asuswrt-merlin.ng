# This is a list of regular expressions matching error messages
# from the cmwifi build which don't indicate real errors.
# NOTE: the preferred solution is always to avoid printing
# bogus error messages in the first place. Swallowing or
# modifying them is a fallback option for cases we cannot
# otherwise fix, especially in third-party code.
# If a matching RE contains a () capture group the captured
# parts will be modified, if not the entire line is dropped.
#
# Matched capture groups are modified by inserting spaces such
# that "fatal:" becomes "f a t a l :". These lines remain
# readable but are no longer found by the error grepper.
#
# It's recommended to use one or more capture groups in each RE
# so the line isn't dropped entirely which could be misleading.
