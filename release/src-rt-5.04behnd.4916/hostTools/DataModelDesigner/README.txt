As of the 6.2.0 release, the CMS Data Model Designer is no longer supported.

Since the data model files are now mature, most developers just edit the
data model files directly using a text editor.  Anyways, there are many
features and attributes that the Data Model Designer does not support, so you
will have to directly edit the data model to see or edit them.

If you still want to use the CMS Data Model Designer, you can find the
pre-compiled binary in previous releases (REL_6.1.1 or earlier).
